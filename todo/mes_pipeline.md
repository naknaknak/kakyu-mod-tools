# MES Reverse-Engineering Phase Roadmap

This file defines the capability gates and default execution order for the
original-MES pipeline. It does not own implementation checkboxes. Each live
work item remains in exactly one domain tracker linked below.

The phases are maturity gates, not a claim that implementation happened in a
strictly linear order. Later-phase prototypes already exist, but they do not
close an earlier gate. A defect found by a later phase can return the current
focus to an earlier gate without discarding the later work.

## Phase 1 — Lossless Binary Reader

The gate is closed when authoritative MES/LIB payloads can be read without
semantic guesses or byte loss:

- bounds-check the container and address table;
- preserve bootstrap, entries, code-relative coordinates, raw bytes, and
  source fingerprints;
- reject malformed input without reading or writing outside the payload; and
- reproduce the same structural document deterministically from unchanged
  source bytes.

Opcode, text, or native-effect meaning is not a Phase 1 requirement.

## Phase 2 — Opcode Dumper

The gate closes when every consumed instruction or compound native record has
one exact `[start, end)` range and retained raw bytes:

- known forms expose typed operands;
- unresolved forms stop as one byte-preserving opaque boundary rather than a
  guessed series of one-byte commands;
- context-sensitive expression, string, and native payload bytes cannot appear
  as sibling shadow commands;
- noncanonical forms fail closed; and
- the indexed-intro and shared-library corpus inventories are deterministic.

MA-07 fixes the confirmed native presentation family. MA-08 closes the final
archive-wide gate and revalidates Phase 3 and Phase 4 consumers.
Confirming every native pixel or input effect is not required when the complete
record is accurately retained and labeled unresolved.

## Phase 3 — String Extractor

Only a Phase 2-owned string operand or confirmed character-stream context may
produce a message row:

- preserve source offset, raw bytes, hash, and encoding diagnostics;
- distinguish CP932 dialogue, record-list strings, resource names, and native
  character streams;
- retain invalid or truncated text as raw evidence instead of replacement
  dialogue; and
- prove the negative space: native, expression, and opaque payloads do not
  generate false strings.

The extraction gate is closed: MA-08 repeats the archive-wide negative-space
audit against the closed Phase 2 record inventory with no native, expression,
or opaque payload promoted as a message.

## Phase 5 — Decompiler

Typed instructions, expression ASTs, CFGs, and traces are prerequisites, not a
completed decompiler. The gate requires a provenance-preserving high-level IR
and readable deterministic output:

- default to a Python offline decompiler consuming the language-neutral Phase
  1-4 handoff from the Python authority; existing GDScript CFG/evidence export,
  runtime validation and Godot integration remain available;

- lift expressions and low-level instructions into source-qualified
  statements;
- structure `if`/`else`, loops, dispatch, and call/return only where the CFG
  proves that structure;
- preserve irreducible flow with labels/gotos and unresolved behavior with
  explicit native or opaque nodes;
- keep every output node traceable to original offsets and raw-byte identity;
- attach evidence status without inventing character, state, place, or event
  names; and
- prove CFG/HIR coverage equivalence across the supported corpus.

The live Phase 5 work is `mes_analyzer.md` MD-01 through MD-04.
MD-01 freezes the lossless linear `kakyu_mes_decompiler_ir/v1` baseline;
MD-02 closes the proof-bounded structuring step. Its bounded same-region `if`/`else`,
guard/value-dispatch, natural-loop, and literal shared-call return-certificate
layers are available. An execution-aware anchor fallthrough layer masks exact
native payload nodes, projects certified literal calls to their physical resume
nodes, and feeds natural-loop dominance. A separate bounded cross-region layer
now proves or rejects unique all-path join relationships without promoting
surface `if` syntax. Compound/irregular state-equality guard dispatches also
have a bounded exact predicate projection without guessed `switch` syntax.
Registered and external call families retain typed selectors/targets, exact
physical resume coordinates, and explicit no-return-edge fallbacks when the
callee body or runtime registry binding is not supplied. MD-01 through MD-04
are closed.
Its first JSON layer assigns source-qualified numeric/literal identities while
leaving every unsupported semantic alias explicitly unresolved.
The renderer-input core now joins those annotations to the complete low-level
fallback and proved reducible conditionals with one source-map row per linear
node. Renderer-input v2 also retains and source-maps the guard/value/predicate,
cross-region-join, and call proof family. Renderer-input v3 additionally binds
the source-qualified library/shared-return/execution chain and reversible
natural-loop envelopes. Pseudocode v1 now emits deterministic source-order JSON
and optional derived text with complete node coverage and exact per-line
reversal. MD-04 owns the remaining corpus/equivalence closure.
Its first executable contract is
`kakyu_mes_decompiler_equivalence_audit/v1`: one renderer-v3/pseudocode-v1
pair must retain a complete source partition, one-to-one node, structure, and
overlay rendering, exact source reversal, and an explicit unresolved
inventory. The authoritative GROUND sample and complete 1,016-entry aggregate
both pass.
The bounded Python aggregate consumer now exists and keeps only compact
per-entry hashes/counts while processing one handoff at a time. The source-bound
handoff-spool exporter also exists and passes a one-entry authoritative run.
Per-entry immutable validation reuse now removes recursive proof/composer replay
without changing the compact audit hash. Bounded process-level scheduling also
restores manifest order and emits byte-identical serial/parallel reports on an
authoritative eight-entry sample. The complete source-bound corpus contains
18,079,488 code bytes and 2,390,675 linear nodes; two four-process runs produce
byte-identical compact reports while every coverage/reversal invariant passes.
MD-04 and Phase 5 are closed.

## Phase 6 — Compiler

The gate is a general safe assembler, not the existing equal-length text
patcher:

- editable lossless IR and a byte-identical no-op rebuild;
- variable-length record and message assembly;
- address-table, branch, continuation, call, and entry relocation;
- preservation of opaque records and rejection when an unresolved relocation
  would cross one;
- reopen, target, semantic-diff, and decompile/compile equivalence checks; and
- a distinct compatibility claim for remake output versus original-engine
  output.

The backend work is owned by `mes_authoring.md` MW-01 through MW-07.
MW-01 closes the editable lossless input and byte-identical no-op compiler
baseline across all 1,016 authoritative MES/LIB entries. MW-02 closes the first
length-changing message assembly plus the distinct remake-only UTF-8 overlay
operation. MW-03 closes exact encoded branch and continuation relocation with
independent source-bound changed-MES reopen. MW-04 closes bounded structured
resource, state, and condition editing with same-length/same-width changes and
current-analyzer reopen. MW-05 closes source-bound library, nested-call,
registered-DEF, and variable-length choice-option editing. MW-06 closes
entry-point and remaining control-flow authoring. MW-07 closes the common
source/output semantic-diff and reopen boundary across every compiled family,
including source-bound variable-length ordinary-message and grouped-choice
regressions. Phase 6 is closed for safe structural remake compilation; native
execution compatibility remains a separate unresolved claim.

## Phase 7 — Translation and Event Modding

Phase 7 consumes the compiler but remains split by product responsibility:

- `mes_authoring.md` owns translation catalogs, encoding policy, structured
  MES edits, and editor-side validation;
- `event_player.md` owns original-only analysis/playback, choices, terminals,
  catalog regression and the bounded input/UI cleanup;
- `presentation_audio.md` owns actual pixels, AX cadence, input, surfaces, and
  audio transport;
- `media_editors.md` owns edited media writers/previews and original-reference
  inspection handoff; modified-media playback is outside Event Player;
- `workspace_distribution.md` owns portable packages, provenance, application
  handoff, clean-environment checks, and leakage rejection; and
- `manual_verification.md` owns accumulated original-engine and GUI checks.

Remake UTF-8 overlays, equal-length CP932 replacement, and seeded Event Player
routes are useful Phase 7 foundations. They do not constitute general
translation or event-modding completion.

## Status Rules

- This roadmap owns phase definitions and gate status. Repository-wide execution
  order moved to `TODO.md` on 2026-09-05, because ordering by blocking condition
  crosses domains that a phase roadmap does not span; the phase order still
  applies within the MES pipeline.
- Domain trackers own all live checkboxes and implementation detail.
- A phase is `Closed` only after its gate, proportionate verification,
  specification evidence, and coherent commits are complete.
- Later prototypes do not close an earlier gate, and an earlier backfill does
  not erase already verified later capability.
- Unknown meaning stays numeric, native, or opaque until authoritative ARC/EXE
  evidence supports a stronger name.
